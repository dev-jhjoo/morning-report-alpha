morning-report-alpha를 점진적으로 발전시켜, 등록 종목에 대해 매일 아침 (1) 뉴스 수집 (2) AI 투자심리 점수 산출 (3) 실제 당일 주가 수집을 데이터로 누적 저장하고, 투자심리 점수와 주가의 상관관계를 장기적으로 분석하는 시스템 + 최종적으로 대시보드를 구축하는 것이 목표.

현재(2026-06-30)는 MVP 단계: 텔레그램으로 일회성 리포트만 발송하고 데이터 저장이 없음. 다음 발전 축은 "데이터 영속화(저장)".

**Why:** 단순 알림봇이 아니라, 심리지표의 예측력을 검증하는 데이터 자산을 쌓는 것이 본질적 목적.
**How to apply:** 기능 제안 시 "데이터를 어떻게 누적/저장하느냐"를 우선 고려. 대시보드 같은 표현 계층은 데이터가 쌓인 뒤. 게으르게: GitHub Actions가 이미 인프라이므로 별도 서버/DB 도입 전에 리포지토리 커밋(JSON/CSV) 같은 가벼운 저장부터.
